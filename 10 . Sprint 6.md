## RESUME (alohan hiala ramose)
- 3 ter: determination url misy `{}` 
	- tokony capable mamaly `etudiant/{id}` 
	- tsy mbola misy mandefa donnees/variable
	- na inona na inona valeur an {id} dia le method `get(int id)` no maka azy
	- dynamique le valeur, fa atao null aloha
```java
	class EtudiantController {
		@url("/etudiant/{id}")
		get(int id) {
			/*
				id == null
				normal zany hatreto
				satria atao ze tsy amoahan le framework exception
				rehefa misy {}
			*/
		}
	}
```

- 6 tsotra
	- rehefa mitovy nenaran le variable avy @ `req.getParam` sy le anaran le argument amle map dia tonga dia apetraka amle ordre an le parametre (vao misy var2 amle argument dia req.getParam(var 2))
	- raha tsisy dia valeur null no miasa
```java
	class EtudiantController {
		@url("/etudiant/{id}")
		get(String var2, int id) {
			/*
			anaty frontServlet mijery hoe
			req.getParam("var2").exists()
			if exists dia le String var 2 io = req.getParam("var2")
			*/
		}
	}
```
- 6 bis
	- raha misy `@RequestParam`
	- raha argument ka misy @RequestParam(int id)
		- verifiena raha misy an le variable anaty getParam 
		- na tsisy var 1 ary anaty getParam
		- -> le annotation no mitondra fa tsy le var 1
```java
class EtudiantController {
	@url("/etudiant/{id}")
	get(@RequestParam(int id) var1, String var2, int id) {

		*/
	}
}
```
