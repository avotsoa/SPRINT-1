===============================================
  FRAMEWORK MVC RESUME - DEPLOYMENT AUTOMATIQUE
===============================================

QUICK START
-----------

1. Configurer votre Tomcat (une seule fois):
   - Editez config.ps1
   - Changez $TOMCAT_HOME avec le chemin de votre Tomcat
   
   Exemple:
   $TOMCAT_HOME = "C:\apache-tomcat-10.1.28"

2. Compiler et deployer automatiquement:
   .\build.ps1

3. Demarrer Tomcat (si pas deja demarre):
   Allez dans Tomcat/bin et executez startup.bat

4. Tester:
   http://localhost:8080/FrameworkResume


AVANTAGES
---------

✓ UN SEUL SCRIPT : build.ps1 fait tout
✓ DEPLOIEMENT AUTOMATIQUE : Le WAR est copie dans Tomcat/webapps
✓ SUPPRESSION AUTOMATIQUE : L'ancien WAR est supprime avant le nouveau
✓ DETECTION INTELLIGENTE : Trouve Tomcat automatiquement
✓ CONFIGURATION SIMPLE : Editez config.ps1 si necessaire


WORKFLOW DE DEVELOPPEMENT
--------------------------

1. Modifiez votre code Java
2. Executez: .\build.ps1
3. Le WAR est automatiquement deploye
4. Rafraichissez votre navigateur

Plus besoin de copier manuellement le WAR!

AIDE
----

1. Verifiez que Tomcat est bien installe
2. Editez config.ps1 avec le bon chemin
3. Ou definissez la variable CATALINA_HOME

Pour plus d'informations, consultez GUIDE.md
